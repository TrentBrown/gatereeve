Token Burn Dashboard For All Sources

Skill name: token-burn-all-sources

Build a token-burn dashboard that tracks Codex, Claude Code, Claude chat, and ChatGPT on the same axes, with exact and estimated usage kept visibly separate.

Use this skill when the user wants one dashboard across Codex, Claude, and ChatGPT.

Workflow

  • Copy assets/dashboard-starter/ into the user's chosen project folder.
  • Read references/data-contract.md, references/dashboard-spec.md, and references/privacy-and-public-data.md.
  • Read references/source-notes.md for source-by-source collection rules.
  • Inventory which sources the user actually uses.
  • Pull exact logs first: Codex and Claude Code where available.
  • Estimate Claude chat and ChatGPT only after interviewing the user or inspecting user-approved local artifacts.
  • Normalize every source into one daily row and one local timezone.
  • Run the starter app locally and verify all five views render.
  • Scrub private detail before deploy or sharing.

Source Rules

  • codex_tokens: exact when local Codex logs include token usage.
  • claude_code_tokens: exact when Claude Code logs include token usage.
  • claude_code_calls: count meaningful Claude Code sessions or calls.
  • claude_chat_est: estimated unless exact provider logs exist.
  • chatgpt_est: estimated unless exact provider logs exist.
  • total: sum of all source columns.

Done Means

  • npm install succeeds.
  • npm run build succeeds.
  • All four source lanes appear on the dashboard.
  • Exact and estimated labels are obvious.
  • The dashboard answers: what work should the computer do next?
