<section aria-labelledby="mechanism"><h2 id="mechanism">The cleanup boundary is the mechanism</h2><p>Disabling happens synchronously, before the first persistence call. The <code>try</code> covers both the call and its awaited result; <code>finally</code> restores availability whether persistence resolves or throws. There is no <code>catch</code>, so error handling remains the caller’s responsibility.</p><div class="cols"><article><h3>Original helper</h3><pre><code>export async function save(button, persist) {
  await persist();
  button.textContent = 'Saved';
}</code></pre><p class="source">Base · editor.js:1, reformatted for reading</p></article><article><h3>Changed helper</h3><pre><code>export async function save(button, persist) {
  button.disabled = true;       // before persist()
  try {
    await persist();
    button.textContent = 'Saved'; // success only
  } finally {
    button.disabled = false;    // either outcome
  }
}</code></pre><p class="source">Head · <a href="../visual-input/editor.js.txt">editor.js:1</a>, reformatted and annotated</p></article></div><p>The label is unchanged during the wait.
