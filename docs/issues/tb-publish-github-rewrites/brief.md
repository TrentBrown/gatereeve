# Brief - tb-publish-github-rewrites

Closes #155. Light rigor; goal autonomy granted by the human for this run.

## Goal

`review.publish` succeeds when a reviewer's summary or finding text quotes
text that GitHub rewrites on write, starting with the JSON-style NUL escape
(a backslash, `u`, then four zeros). Before the PR description is written,
the rendered review section neutralizes such text in a deterministic,
readable way, so the byte-for-byte read-back still compares equal. The
read-back check itself stays exact: any other difference between the written
and read-back section still fails publication, and the merge-authorization
check still compares the live section with a fresh rendering.

GitHub's actual behavior on such text is observed once against a real PR
and pinned by a test (the observed rewrite is recorded in the findings log
and in the test's comment).

## Scope

In: `plugin-src/shared/resources/protocol/current/publication.js` (the
rendering helpers that sanitize model-authored text), its staged desktop
copy regenerated by `stage:protocol`, and focused tests in
`cli/test/current-delivery-targets.test.js`.

Out: any general relaxation of the read-back comparison (for example
normalizing or ignoring differences after the write); other GitHub text
transformations not observed to break the read-back; `execution.js`,
`boundary-review.js`, storage roots and briefScope (owned by other open
issues).
