# GitHub and gh round-trip probe (#155)

Recorded 2026-11-26 on draft PR #160 with gh 2.97.0. Each probe was written with
`gh pr edit 160 --body-file <probe>` and read back three ways:
`gh pr view 160 --json body -q .body` (gh), the REST API
(`GET repos/TrentBrown/gatereeve/pulls/160`, field `body`) and GraphQL
(`repository.pullRequest.body`), the last two through curl with the gh token,
which skips gh's response sanitizer. Values are shown as Python `repr()`.
The probe text has since been replaced by the PR description.
