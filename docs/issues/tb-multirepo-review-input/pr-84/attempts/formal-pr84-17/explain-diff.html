1. The backbone stays

Background for a first-time GateReeve reader

An agent can implement a change and run checks, but a useful delivery process also needs a record of what was agreed, what was actually assessed, and which actions a person authorized. GateReeve keeps those commitments and checks whether the evidence supports the next milestone.

A gate is an obligation, such as independent code review. A verdict says what an evaluator found. A receipt says how the evaluation ran. Applicability asks whether that result still supports the current candidate. Human authority is a separate question: passing tests does not authorize a merge.

The retired --checks shortcut rejects with replacement guidance because it cannot express this commitment.

Exceptions and resumption preserve truth

A scoped human exception preserves the original FAIL and known consequences. It does not manufacture PASS, authorize an unnamed merge, or survive a relevant change to risk. A requirement amendment retains old and new commitments. Resuming old work establishes a current run using preserved documents and substantiated authority; it does not reinterpret old events as new passage or automatically restart an unchanged interview.
