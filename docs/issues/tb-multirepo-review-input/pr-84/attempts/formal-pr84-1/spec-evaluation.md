## Scope, contradictions and remaining limits

The broad source/core/CLI/plugin/Desktop cutover is authorized by this spec; it is not scope creep merely because the original issue concerned shared review records. The direct-cutover design expressly supersedes compatibility, old replay, mandatory pilots and benchmark proposals. No requirement for publication, remote installation, production credentials or external branch-protection setup was added.

The retained verification's overall PASS describes its executed checks, not a valid all-rubric acceptance verdict. Its local runtime smoke does not establish the package Python allowlist. Initial skipped live evaluation was addressed only by the explicitly supplied later receipt. Host coverage is bounded subprocess/adapter coverage; installed-host activation and arbitrary command interception are not claimed.

The design includes historical draft-status text followed by explicit approval; that is not a requirement contradiction. CLI README's retired advisory/readiness instructions do contradict the current interface and should be corrected. Missing historical evidence is surfaced without fabricating replacement bytes; that mechanism does not cure CR-5 at the implementation boundary.

A refreshed pinned candidate and focused regression evidence are required for the failed rows. Prior passing evidence may be retained where applicability remains valid; this verdict does not demand blanket reruns or authorize implementation, merge, release, installation or deployment.
