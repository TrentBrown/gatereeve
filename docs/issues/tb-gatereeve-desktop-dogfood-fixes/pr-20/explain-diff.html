GateReeve becomes pleasant to dogfood

Python discovery now finds the installation the user actually installed; Setup no longer distorts the workspace; workflow artifacts stay current; and Markdown gains safe emphasis and links without turning the observer into a browser or file explorer.

Background

GateReeve Desktop is an observer over one explicitly selected worktree. The Electron main process owns privileged operations: filesystem-backed canonical reads, native dialogs, and opening a validated URL. A sandboxed preload exposes a small named API. The renderer presents only the canonical snapshot and requests artifact details by their canonical IDs.

Why the bugs appeared together

They all sat at the seam between an observed external fact and its desktop presentation. Finder-launched applications inherit a restricted environment, so the first executable Python was Apple's old 3.9 even after Homebrew installed a newer one. Setup had been structurally separated from the normal workspace, so selecting it changed the grid. Artifact selection remembered an ID but not the file fingerprint, so snapshot changes did not cause a new named read. Finally, the intentionally small Markdown renderer recognized blocks and code but not ordinary inline emphasis or navigation.

Invariant: improving convenience must preserve observation boundaries. GateReeve may choose a canonical artifact or open a validated web URL, but Markdown can never nominate a filesystem path for the main process to read.

Intuition

1. Select by compatibility, not mere existence

candidates = [/usr/bin/python3, /opt/homebrew/bin/python3]
/usr/bin/python3       → 3.9.6  → keep looking
/opt/homebrew/bin/...  → 3.14.0 → select

The discovery layer now returns every executable match in deterministic bounded order. Setup owns the policy question—“is this Python new enough?”—and stops at the first compatible answer. An explicit override is still authoritative and therefore never falls back.

With no worktree, Setup belongs in onboarding. With a worktree, the same DOM node moves into the ordinary workspace content area. The sidebar never changes owners or width.

3. Treat the artifact fingerprint as cache coherence

selected = { id: "interview", fingerprint: modifiedAt + size }
new snapshot arrives
if same id and different fingerprint:
    issue a new named read
    accept only the newest request sequence

The snapshot watcher was already the correct change trigger. The renderer now compares fingerprints and rereads only the selected item—no poller is added. A sequence number prevents an older asynchronous response from replacing newer content.

4. Parse Markdown into nodes, then resolve links by capability

The tokenizer emits text, code, strong, em, and accepted anchor nodes. Link resolution is separate: HTTP(S) becomes a validated native-open request; a relative path must exactly match the current canonical artifact inventory; a fragment stays in the current viewer. Everything else remains visible literal text.

Artifact failure states

A failed reread does not blank the document. GateReeve keeps the last good DOM, inserts a visible stale warning, and leaves Refresh available. If the artifact disappears from canonical inventory, it does clear the viewer because retaining it would falsely imply that the file is still governed and available.

Safety and evidence

  • No dependency or lockfile changed.
  • No continuous polling was added; existing snapshot publications trigger refresh.
  • No artifact content is assigned through innerHTML.
  • Markdown images remain literal and cannot load local or remote content.
  • Relative links can select only existing, safe entries in the current canonical inventory.
  • External URLs are limited to credential-free HTTP(S) and revalidated at the privileged boundary.
  • Window navigation and popup denial remain in force.
Verification: 92/92 Desktop tests pass. The production renderer visual fixture passes at ordinary and minimum dimensions. Packaged macOS signing, notarization, architecture, Homebrew, and installed-app checks intentionally remain in the post-merge release phase.
