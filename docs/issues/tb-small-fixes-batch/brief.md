# Brief - tb-small-fixes-batch

Closes #146. Light rigor; mandated autonomy granted by the human for this run.

## Goal

Ship the small, independent fixes listed in issue #146, each with a focused
test or a doc correction:

1. Verification and `metrics import --format github` no longer depend on
   `gh api --slurp` (absent in `gh` 2.46, which Ubuntu ships): paginated job
   lists are read with `--paginate --jq`, which older `gh` supports.
2. The `merge.prepare` draft requirement is explained up front, with no
   contract change: refusing an open PR that is ready for review names the
   reason and the fix (`gh pr ready <n> --undo`), and the light-run and
   PR-boundary procedures and PROTOCOL.md tell agents to open GateReeve PRs
   with `gh pr create --draft`. Accepting non-draft PRs is a follow-up issue.
3. PR A open items:
   - the CLI isolation-evidence script also counts execution records
     (`records` table) and fails when the suite adds records for a project the
     shared store did not know before;
   - `inspectScratch` survives a tombstone removed between `readdir` and
     `lstat` (counts it as zero files instead of failing the inventory);
   - the inventory's file count measures each run against the `runs`
     directory's filesystem, so a run whose folder is a mount root is not
     walked (quick doctor inventory included);
   - PERFORMANCE.md's `purge-test-data --apply` example names the required
     `--workflow` / `--workflows-file` selection;
   - a sweep test pins `REGENERABLE` to the exact spec list, instead of only
     iterating the constant;
   - slice-1 escalation (delayed SIGKILL in `runAgentProcess`) walks
     descendants only from roots that are still the same process (child not
     yet exited; recorded PIDs whose start time still matches), so a reused
     PID's children are never killed.
