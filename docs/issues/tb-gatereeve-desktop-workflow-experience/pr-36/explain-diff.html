PR #36 · feature-final review

Quieter hierarchy, sharper inspection

GateReeve’s approved interface-polish prototype is now the production Electron renderer. The change refines how users distinguish governed current state from what they are inspecting, makes the PR boundary read as a dependency graph, and reduces the right panel to one active artifact without throwing away its internal identity model.

Focused diff: ee29569..3b45e64. Developer ID signing, notarization, publication, and deployment are not part of this PR.

1 · Selection grammar

Current and selected stay different without moving the layout

Before

Dark hover fills reduced legibility. Current, Selected, enum subtitles, selection summaries, and empty milestone prose competed for space and appeared or disappeared as selection changed.

After

Rail, slice, and gate items share a light surface, full-card hover, inset selected outline, visible focus, and status-colored edge. aria-current, aria-pressed, labels, and status text preserve independent meaning.

Human-facing labels use sentence capitalization, and canonical DELIVERING_SLICES appears as Implementing. Real selected-state milestones still render; only the noisy empty message is gone.

3 · Artifact companion

One active item, compact controls

Presentation

The visible tab strip, Inspector heading, count, large artifact title, and artifact Refresh action are suppressed. Filename and quiet type metadata sit on one toolbar line.

Actions

Markdown toggles between rendered and source views. Copy, split Open/reveal/copy-path, and expand/restore controls use named icon buttons. Escape restores an expanded inspector.

Reversibility

The serializable per-project tab collection and canonical identity remain internal. Hiding the panel preserves it, and reopening an artifact activates its existing identity.

4 · Quiet context and stable geometry

Details appear where they help

  • Watching local changes opens a modal summarizing independent Local, Git, and GitHub observation.
  • An invalid candidate leaves the project list available but hides stale tabs, hierarchy, and inspector content behind one exclusive diagnostic.
  • Explicit grid columns keep the central workspace in the correct track when the project sidebar or inspector is hidden.
  • Settings, refresh, and the two sidebar controls use familiar masthead icons aligned at the far right.
  • The visual fixture now imports production HTML, CSS, and renderer modules directly with cache-busting; there is no fixture-only presentation patch.
