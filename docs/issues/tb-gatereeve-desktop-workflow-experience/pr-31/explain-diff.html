Background

Intuition

1. A failed choice is not a failed application

Suppose Project A is valid and active. The user tries Project B, whose feature record pins an unsupported model. The old presentation could bury that failure because A remained selected. The new presentation keeps A active and opens a full diagnostic for B. Selection safety and useful feedback no longer compete.

Before

B is not admitted, but the valid workspace for A can make the reason feel absent or detached.

After

A remains selected. A collapsible alert names B's directory, feature record, pinned model, failed checks, safe next steps, and non-mutation guarantee.

2. Desired width and rendered width are different facts

The workspace store may remember a desired inspector width of 720px. At a 940px window, the sidebar and the central workspace still need room. PR #31 keeps 720 as the user's session value while capping the rendered track to what the viewport can safely contain.

rendered inspector = min(
  requested inspector,
  viewport - sidebar - minimum center - scrollbar allowance
)

This distinction matters because resizing the window should not destroy the user's preference. A later, wider window can honor more of the requested width.

3. A smoke test must fail the process, not merely print a complaint

The previous startup handler set an exit code and then asked Electron to quit, but the command could still finish successfully. The new handler calls app.exit(1). A broken renderer contract now produces both structured evidence and a nonzero command result.

The smoke contract measures rendered geometry

The runtime check no longer trusts only hidden or ARIA state. It measures all three workspace children, requests the maximum inspector width, proves the actual track is constrained, returns to 400px, checks focus restoration, and rejects any document-level overflow.

Review finding resolved inside the sliceThe first formal attempt found that the normal 400px case passed while a 720px request could overflow. The attempt was returned to remediation; the viewport cap and expanded smoke are part of the reviewed head.
