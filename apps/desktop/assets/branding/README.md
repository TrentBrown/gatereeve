# GateReeve branding

`gatereeve-rolling-vale.png` is the approved source artwork for the GateReeve
application icon. Human review selected the V1 Rolling Vale direction on
2026-08-27. The source is a 1254 x 1254 RGB PNG with SHA-256
`7ff177774041fa451edbbaca4e1409f6f46bc782df24cd3ea7345b9f89529cb7`.

The macOS packaging script derives the standard iconset sizes and `.icns` file
from this source with macOS `sips` and `iconutil`. Generated icon files belong
under the ignored `dist/` tree; the reviewed source remains the durable asset.

The artwork was generated for this project with OpenAI's image-generation tool.
