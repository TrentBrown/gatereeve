# Completion after external integration

Use the current `run.resume-current` entry if the feature has no current run.
Preserve old records and substantiate current commitments from observed approvals.
Use `integration.observe` to fetch and verify the reviewed content on the configured
integration/release branch. Integration is a fact, not a quality verdict.

Refresh missing current gate evidence, retain accepted exceptions visibly, run
required finalization against the observed integrated source, verify retention and
check/pass the completion milestone. Never invent acceptance or merge permission
because an external merge occurred. See [PROTOCOL.md](../PROTOCOL.md).
