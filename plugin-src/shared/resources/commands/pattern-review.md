# Pattern review

Use current `gate.execute` for the `pattern` obligation with the selected provider
and model. The execution service invokes the trusted pattern helper on each pinned
repository base/head, retains active rule bytes, deterministic trigger decisions,
rule stack and overrides, and supplies them to the evaluator. Missing scope is
unavailable; initialize an intended scope using pattern-init. An existing empty
scope is a visible warning, not meaningful coverage.

Evaluate triggered rules; explain agentic trigger decisions. Unresolved manual
reviews and blocker failures prevent PASS. Findings cite current source and rule
identity. Scoped human exceptions remain distinct from verdicts. Changed rule
bytes or trigger inputs invalidate earlier pattern proof. Do not append raw
implementer narrative or reconstruct missing evidence.

For standalone pattern inspection, use `pattern_tool.py review-inputs` and the
pattern-review skill. Formal passage always uses the current core described in
`<plugin-root>/resources/PROTOCOL.md`.
