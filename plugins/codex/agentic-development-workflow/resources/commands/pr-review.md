Use `gate.execute` for the code obligation with an explicit native provider/model.
Prepare pinned requirements, source and scope first. A fresh evaluator independent
of the implementer checks changed behavior and interactions, verifies affected
prior findings and searches for new supported defects. Prior results are context,
not authority. Supply bounded reviewer history and labeled disposition claims;
never raw implementer conversation. Findings cite current evidence and an approved
criterion or applicable code-review rule. Unrelated advice is nonblocking.
Code/spec may share one fresh execution with separate verdicts. Preserve original
FAIL/UNAVAILABLE; only actual current proof or a scoped exception admits passage.
