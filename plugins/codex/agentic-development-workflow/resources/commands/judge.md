# Judge

Read `<plugin-root>/resources/PROTOCOL.md` for the current operation/input contract.

The required `review` already covers independent compliance judgment. For an
explicit additional perspective, use `gate.execute` to request supplemental `judge` through actual native independent execution. Consume
current Verification evidence; use approved requirements, full selected rubric,
pinned source and bounded relevant reviewer evidence. Score every selected
criterion with actual evidence. Check gaps, contradictions, scope creep and
unsupported completion claims. A supplemental Judge adds another independent perspective; it is not required
after a complete consolidated review.
The implementer cannot author the Judge verdict. Missing evidence, role or output
qualification stays UNAVAILABLE. A waiver requires the actual scoped human
instruction and preserves the original outcome.
