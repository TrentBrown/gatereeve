# Portable Core Policy

This profile supplies only cross-organization software workflow behavior.

- Discover protected branches and repository conventions from repository-local
  instructions and configuration.
- Use the configured `agentic-workflow.branchPrefix`; never infer a user's
  initials or identity.
- Preserve unrelated work and require explicit approval for destructive or
  externally visible actions.
- Treat optional specialist integrations as capabilities, not prerequisites.

The lifecycle, gates, branch documents, decisions, review sequence, and
verification requirements remain defined by `WORKFLOW.md` and `STANDARDS.md`.
